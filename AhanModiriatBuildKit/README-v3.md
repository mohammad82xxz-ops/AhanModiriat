# آهن‌مدیریت — روش تست و ساخت شاخه فعلی

این پوشه برنامه محلی Python/SQLite را نگه می‌دارد. برای آزمایش، Python 3.10+ لازم است.

## اجرای تست پایه
در همین پوشه:
```bat
python -m py_compile app.py test_smoke.py
python test_smoke.py
```
تست‌ها از مسیر موقت `AHAN_DATA_DIR` استفاده می‌کنند و نباید دیتابیس واقعی را تغییر دهند.

## ساخت Windows OneDir
در ویندوز فایل `build.bat` را اجرا کنید. خروجی `dist\AhanModiriat\` است و باید کل پوشه را کنار هم نگه دارید. ساخت EXE در محیط لینوکس محلی تأیید نشده است؛ برای ساخت ویندوزی از workflow در GitHub Actions استفاده کنید.

## نسخه پشتیبان و ایمنی
پشتیبان‌گیری خودکار پیش از شروع برنامه انجام می‌شود و ۷ نسخه آخر نگه داشته می‌شود. دیتابیس، پشتیبان و اطلاعات مشتریان را به مخزن عمومی commit نکنید.

## وضعیت قابلیت‌ها
این شاخه در PR فعلی شامل زیرساخت پشتیبان‌گیری، SQLite WAL، ثبت رخداد و ابزار تست/ساخت است. این PR به‌تنهایی به معنای تکمیل همه ۲۱ درخواست حسابداری نیست؛ قابلیت‌های کامل‌تر و تست‌های گسترده‌تر در بسته منبع نسخه ۳٫۰ ارائه‌شده در همین گفتگو قرار دارند.
