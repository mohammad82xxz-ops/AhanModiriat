# آهن‌مدیریت — راهنمای تست و ساخت شاخه فعلی

این پوشه برنامه محلی Python/SQLite را نگه می‌دارد. برای اجرای برنامه و تست‌ها Python 3.10 یا بالاتر لازم است.

## اجرای تست پایه

در همین پوشه:

```bat
python -m py_compile app.py test_smoke.py
python test_smoke.py
```

تست‌ها باید از مسیر موقت `AHAN_DATA_DIR` استفاده کنند و نباید دیتابیس واقعی را تغییر دهند. مجموعه کامل تست‌های خودکار در workflow مخزن اجرا می‌شود.

## ساخت Windows OneDir

در ویندوز فایل `build.bat` را اجرا کنید. خروجی در `dist\AhanModiriat\` قرار می‌گیرد و برای اجرا باید کل پوشه کنار هم باقی بماند. ساخت ویندوزی از طریق workflow GitHub Actions نیز بررسی می‌شود؛ تا موفقیت Job ویندوز، ساخت بسته را تأییدشده فرض نکنید.

## نسخه پشتیبان و ایمنی

پیش از استفاده واقعی، از دیتابیس نسخه پشتیبان مستقل تهیه کنید. دیتابیس، نسخه‌های پشتیبان و اطلاعات مشتریان را به مخزن عمومی commit نکنید. تست‌های خودکار باید روی داده و مسیر موقت اجرا شوند.

## وضعیت دامنه در PR شماره ۴۱

در شاخه این PR، صفحه صندوق و گردش دستی، ایجاد وام و قسط جدید، پیشنهاد خرید و گزارش سود به تفکیک مشتری از رابط فعال خارج شده‌اند. حداقل موجودی و هشدار کمبود کالا فعال است. سوابق تاریخی صندوق/بانک و وام‌ها در دیتابیس‌های موجود حفظ می‌شوند و سود/کارمزد تاریخی وام همچنان در گزارش سود خالص اثر دارد.

این بازنشستگی قابلیت‌ها به معنی حذف جدول‌ها یا پاک‌سازی داده‌های تاریخی نیست. هیچ مهاجرتی روی دیتابیس واقعی انجام نشده است. وضعیت اجرای تست‌ها و ساخت Windows را فقط از اجرای CI مربوط به آخرین commit شاخه بررسی کنید.
