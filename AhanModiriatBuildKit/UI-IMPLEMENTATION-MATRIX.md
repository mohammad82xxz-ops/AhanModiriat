# وضعیت انطباق UI/UX — نسخهٔ توسعه

## مسیر فایل‌ها

- `AhanModiriatBuildKit/static/tokens.css`: توکن‌های طراحی.
- `AhanModiriatBuildKit/static/app.css`: پوسته، اجزا، جدول‌ها و استایل نمودارها.
- `AhanModiriatBuildKit/static/app.js`: تم، فرمان‌پالت، میان‌برها و قالب‌بندی ورودی.
- `AhanModiriatBuildKit/static/icons.svg`: آیکون‌های محلی.
- `AhanModiriatBuildKit/static/fa.json`: رشته‌های فارسی پایه.
- `AhanModiriatBuildKit/static/print.css`: قواعد چاپ.

این ماتریس ادعای تکمیل برای مواردی که ممیزی یا آزمون کافی ندارند مطرح نمی‌کند.
