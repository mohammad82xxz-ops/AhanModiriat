# آهن‌مدیریت — مدیریت موجودی و حسابداری محلی

این مخزن برنامهٔ محلی مدیریت انبار و حسابداری «آهن‌آلات برادران» است. برنامه روی دستگاه اجرا می‌شود و اطلاعات را در SQLite نگه می‌دارد.

## تغییرات نسخهٔ این شاخه

- دفتر صندوق و بانک با دو حساب اولیه، ثبت دستی واریز/برداشت/انتقال، محاسبهٔ مانده و گردش‌های لینک‌شده به اسناد.
- مهاجرت تکرارپذیر پرداخت/دریافت‌های صریح و قدیمی از خرید، فروش، خدمات، هزینه‌ها، پرداخت اقساط، رویدادهای نقدی و تسویه‌ها؛ برای مبلغ مرجوعیِ نامعلوم چیزی حدس زده نمی‌شود.
- دفتر اشخاص برای ثبت مشتری/فروشنده، نمایش ماندهٔ دریافتنی/پرداختنی، ریز حساب و ثبت تسویه‌هایی که گردش نقدی ایجاد می‌کنند.
- بازیابی فایل پشتیبان با اعتبارسنجی SQLite و جدول‌های اصلی، ایجاد پشتیبان از دیتابیس فعلی پیش از جایگزینی، محدودیت حجم فایل و ثبت رخداد بازیابی.
- تست‌های رگرسیون مستقل برای مهاجرت صندوق، تسویه و مانده اشخاص، و بازیابی پشتیبان سالم/خراب.
- حفظ پوستهٔ RTL و دارایی‌های محلی CSS/JS/SVG، تم روشن/تیره و ساخت ویندوزی OneDir.

## وضعیت تکمیل

**این شاخه همهٔ ۲۱ معیار اولیه را تکمیل نمی‌کند.** دفتر اشخاص هنوز به‌صورت کلید خارجی اجباری در همهٔ اسناد قدیمی وصل نشده است. برخی مسیرهای ویرایش/حذف و واگرد، مرجوعی‌ها، کارت گردش کالا، گزارش سود تفصیلی، انبارگردانی، Excel، صفحه‌بندی کامل و تبدیل فیزیکی همهٔ ستون‌های پولی هنوز پیاده‌سازی یا به‌طور کامل آزمون نشده‌اند. وضعیت هر مورد در [FEATURE-MATRIX.md](FEATURE-MATRIX.md) آمده است. موارد «جزئی» یا «تأییدنشده» تکمیل‌شده محسوب نمی‌شوند.

## اجرا و ساخت

در ویندوز، داخل پوشهٔ AhanModiriatBuildKit فایل run.bat را اجرا کنید. برای ساخت OneDir، از GitHub Actions workflow با نام **AhanModiriat smoke test and Windows build** استفاده کنید؛ خروجی پوشه‌ای در artifact همان اجرا قرار می‌گیرد.

قبل از استفادهٔ واقعی، از دیتابیس موجود نسخهٔ پشتیبان مستقل نگه دارید و گردش‌های حسابداری را با چند سند آزمایشی تطبیق دهید.
