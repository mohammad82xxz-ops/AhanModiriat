# آهن‌مدیریت — مدیریت موجودی و حسابداری محلی

این مخزن برنامهٔ محلی مدیریت انبار و حسابداری «آهن‌آلات برادران» است. برنامه با Python و SQLite اجرا می‌شود؛ اطلاعات در دستگاه کاربر نگه‌داری می‌شوند.

## قابلیت‌های این شاخه

- **دفتر اشخاص:** مشتری/فروشنده، مانده دریافتنی/پرداختنی، ریزحساب صفحه‌بندی‌شده با مانده‌های تجمعی جداگانه، تسویه و شناسهٔ ارتباطی اسناد. اسناد قدیمی بدون بازنویسی متن اصلی به شناسه‌های nullable طرف‌حساب متصل می‌شوند.
- **صندوق و بانک:** مانده حساب‌ها، واریز/برداشت/انتقال و گردش‌های وصل‌شده به مبالغ صریح پرداخت/دریافت. مهاجرت قدیمی تکرارپذیر است.
- **کنترل اسناد:** ویرایش/حذف خرید، فروش و هزینه با کنترل شرایط بازگشت؛ اگر گردش بعدی یا مرجوعی وابسته وجود داشته باشد، برخی عملیات به‌جای بازسازی ناامن مسدود می‌شوند.
- **مرجوعی خرید و فروش:** سند مستقل، محدودیت مقدار نسبت به سند مبدأ، کنترل موجودی، مانده طرف‌حساب، گردش نقدی و اثر مرجوعی فروش بر سود خالص.
- **انبار:** کارت گردش هر کالا، ثبت انبارگردانی با علت، موجودی پس از گردش و پیشنهاد خرید مبتنی بر فروش ۳۰ روز اخیر.
- **گزارش‌ها:** سود کالا و مشتری، سود خالص ماهانه بر اساس تقویم شمسی، نمودار روند فروش/خدمات ماهانه و نمودار تاریخچهٔ قیمت کالای انتخاب‌شده.
- **فایل‌های Excel:** ورود/خروج XLSX برای کالاها و اشخاص (برگه‌های Products و People)، با اعتبارسنجی و رد نام‌های تکراری.
- **پشتیبان‌گیری:** snapshot سازگار با SQLite WAL، نگه‌داری هفت نسخه، دانلود و بازیابی اعتبارسنجی‌شده، به‌همراه پشتیبان از دیتابیس قبل از جایگزینی.
- **قابل حسابرسی:** timestampهای ایجاد/به‌روزرسانی در جدول‌های اصلی و صفحهٔ ممیزی که زمان، نوع رخداد، شناسه و نام فیلدها را نشان می‌دهد؛ مقادیر حساس فرم در متن ممیزی ذخیره نمی‌شوند.
- **رابط کاربری:** پوستهٔ RTL، تم روشن/تیره، فونت متغیر Vazirmatn به‌صورت WOFF2 همراه مجوز SIL OFL 1.1، ارقام فارسی، SVG/CSS/JS محلی، میان‌برهای صفحه‌کلید و command palette. فهرست‌های کالا، خرید، فروش، خدمات و هزینه فهرست‌های کالا، خرید، فروش، خدمات، هزینه، صندوق، اشخاص، انبارگردانی، مرجوعی، ممیزی، وام و تاریخچهٔ قیمت جست‌وجوی SQL و صفحه‌بندی ۵۰تایی دارند؛ کارت گردش کالا و ریزحساب اشخاص نیز ماندهٔ تاریخی درست و صفحه‌بندی مستقل دارند.
- **ساخت ویندوز:** GitHub Actions تست‌های Linux و بستهٔ Windows OneDir را اجرا می‌کند.

## وضعیت تکمیل و محدودیت‌ها

این نسخه نسبت به پیاده‌سازی پایه گسترش یافته و مجموعهٔ آزمون‌های رگرسیون متنوعی دارد، اما **همهٔ ۲۱ معیار به‌طور بی‌قیدوشرط کامل نیستند**. موارد اصلیِ باقی‌مانده عبارت‌اند از: ممیزی بصری و دسترس‌پذیری کامل، تعمیم الگوی صفحه‌بندی و جست‌وجو به همهٔ جداول فرعی/نمایش‌ها، تست مرورگری و ممیزی دیداری تقویم شمسی روی همهٔ فرم‌ها، پوشش یکسان میان‌برها در همهٔ گردش‌ها، احراز هویت چندکاربره و تاریخچهٔ کامل قبل/بعد برای ممیزی، و ممیزی دیداریِ مهاجرت پولی روی دادهٔ واقعی. پیشنهاد خرید قاعده‌محور است، نه پیش‌بینی هوش مصنوعی. محدودیت‌های دقیق هر مورد در [FEATURE-MATRIX.md](FEATURE-MATRIX.md) ثبت شده‌اند.

## اجرا و ساخت

در ویندوز، در پوشهٔ `AhanModiriatBuildKit` فایل `run.bat` را اجرا کنید. برای فایل اجرایی پوشه‌ای، workflow با نام **AhanModiriat smoke test and Windows build** را اجرا کنید و artifact با نام `AhanModiriat-Windows-OneDir` را از همان اجرای موفق بگیرید.

قبل از استفادهٔ عملی، یک پشتیبان مستقل نگه دارید و فرایندهای خرید، فروش، مرجوعی، تسویه و بازیابی را با چند سند آزمایشی و اعداد واقعی کسب‌وکار تطبیق دهید.
