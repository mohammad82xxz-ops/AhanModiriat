# آهن‌مدیریت — وضعیت مخزن

این مخزن پروژهٔ محلی مدیریت انبار و حسابداری «آهن‌آلات برادران» است.

## وضعیت فعلی شاخهٔ main
در commit فعلی، این بخش‌ها ثبت شده‌اند: ویرایش کالا و تبدیل واحدها، پشتیبان خودکار هنگام راه‌اندازی و نگهداری ۷ نسخهٔ آخر، SQLite WAL، ثبت رخدادهای ممیزی بدون ذخیرهٔ مقادیر فرم، پوستهٔ RTL و فاز اول طراحی UI، دارایی‌های CSS/JS/SVG محلی، صفحهٔ `/design` و ساخت ویندوزی OneDir.

**مهم:** این commit هنوز نسخهٔ تکمیل‌شدهٔ همهٔ ۲۱ مورد حسابداری نیست. برخی معیارها مثل دفتر اشخاص با پیوند اجباری سندها به شناسه، انتقال/بازسازی گردش نقدی تاریخی، تمام مسیرهای ویرایش/واگرد، پوشش کامل صفحه‌بندی و تست‌های پذیرش کامل‌تر، در شاخهٔ `main` تکمیل نشده‌اند. از این ZIP نمی‌توان به‌عنوان نسخه‌ای که تمام ۲۱ مورد را اجرا می‌کند یاد کرد.

## ساخت/اجرا
داخل پوشهٔ `AhanModiriatBuildKit`، Python و وابستگی‌های موجود در `requirements-build.txt` را نصب و `run.bat` را اجرا کنید. برای ساخت ویندوزی، از `build.bat` یا اجرای موفق GitHub Actions استفاده کنید.

ماتریس وضعیت هر قابلیت باید مرجع پذیرش باشد؛ موارد «جزئی» یا «تأییدنشده» تا زمان تکمیل و تست عملی، تکمیل‌شده محسوب نمی‌شوند.
