# AhanModiriat — اصلاحات ساخت و داده

## تغییرات
- برنامه از متغیر محیطی `AHAN_DATA_DIR` برای تعیین مسیر پایگاه داده پشتیبانی می‌کند؛ در حالت عادی داده‌ها در پوشه `data` کنار برنامه ذخیره می‌شوند.
- اسکریپت `build.bat` پیش از ساخت EXE، کامپایل نحوی و تست‌های رگرسیون را اجرا می‌کند و در صورت خطا متوقف می‌شود.
- تست‌ها از پوشه موقت جداگانه استفاده می‌کنند تا به پایگاه داده واقعی دست نزنند.
- Workflow گیت‌هاب تست‌ها را پیش از ساخت نسخه ویندوز اجرا می‌کند.

## ساخت روی ویندوز
از پوشه اصلی مخزن، `build.bat` را اجرا کنید. خروجی در `dist\AhanModiriat.exe` ساخته می‌شود و پایگاه داده به‌طور پیش‌فرض در `dist\data\business.db` قرار می‌گیرد.

**مهم:** هنگام جابه‌جایی یا به‌روزرسانی برنامه، از پایگاه داده نسخه پشتیبان بگیرید و پوشه `data` را حفظ کنید.

## محدوده آزمون‌ها
این تست‌ها تبدیل تاریخ، ورودی اعداد و جداسازی مسیر داده را بررسی می‌کنند؛ جایگزین آزمون کامل محاسبات حسابداری و آزمایش نهایی EXE روی ویندوز نیستند.
